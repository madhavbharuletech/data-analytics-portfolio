## 📌 Project Overview

This project analyses a multi-year retail sales dataset to uncover trends, performance drivers, and business opportunities.  
It demonstrates a full analytics workflow — from data exploration and SQL modelling to interactive dashboard reporting.

---

## 🎯 Objectives

- Understand overall business performance  
- Analyse sales trends over time  
- Identify regional and product performance drivers  
- Evaluate customer behaviour patterns  
- Build a reusable reporting layer for dashboards  

---

## 🧰 Tools & Technologies

- SQL Server → Data exploration and modelling  
- Excel → Initial data profiling  
- Tableau → Visualisation and storytelling  
- GitHub → Documentation and version control  

---

## 📊 Dataset Summary

- ~9,800 transaction records  
- ~4,900+ distinct orders  
- USA geographic coverage  
- Transaction line-item level  
- Suitable for time-series analysis  

---

## 🔎 Analytical Approach

### 1️⃣ Data Profiling (Excel)
Validated data quality, formats, and structure.

### 2️⃣ SQL Exploration & Modelling
Performed EDA, trend analysis, and created reporting view  
`vw_sales_analytics`.

### 3️⃣ Dashboard Development (Tableau)
Built an executive dashboard to visualise KPIs, trends, and performance drivers.

---

## 📈 Key Business Findings

### 🧾 Data Overview
- ~$2.26M total revenue  
- Avg. order value ≈ $459  
- Healthy transaction volume  

### ⏱️ Time Trends
- Strong growth from 2017–2018  
- Increasing order volume  
- Peak demand in Q4  

### 🌎 Regional Insights
- West region leads revenue  
- South region underperforms  

### 📦 Product Insights
- Technology drives revenue  
- Phones top sub-category  

### 👥 Customer Insights
- Balanced revenue distribution  
- No single dominant customer
