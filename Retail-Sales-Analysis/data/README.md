# 📁 Dataset Description — Retail Sales Analysis

This folder contains the dataset used for the Retail Sales Analysis project.

## 📊 Data Source

The dataset is based on the publicly available **Sample Superstore** retail dataset, which is widely used for analytics training and demonstration purposes.

It was originally provided by **Tableau** and is commonly shared through platforms such as Kaggle.

## 📄 File Included

**`train.csv`**
Contains transactional retail sales data including orders, customers, products, and sales metrics.

## 🧾 Dataset Purpose

The dataset was used to:

* Perform Excel/SQL exploratory data analysis
* Identify sales trends and performance drivers
* Build a reporting layer for visualisation
* Create dashboards to communicate insights

## ⚠️ Note

This dataset is used strictly for learning and portfolio demonstration purposes and does not represent real business data.
